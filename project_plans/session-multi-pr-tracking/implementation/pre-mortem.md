# Pre-mortem: session-multi-pr-tracking
**Date**: 2026-11-03

Scope: causes NOT already covered by Known Risks K1-K9 or the six repair logs in `plan.md`. Confidence labels: VERIFIED (command run or file opened in this pass), INFERRED (reasoned, not run).

Production facts gathered read-only from the live DB `~/.stapler-squad/workspaces/d685c4b1a423cca3/sessions.db` (1.4 GB, WAL):
- 522 sessions, 292 with `github_pr_number > 0`, only 33 with the terminal flag true (259 legacy PRs will be seeded `unknown`, non-terminal). 118 of the 292 have an empty `github_pr_url`; 2 have no owner/repo (backfill skip class). All hosts are github.com or NULL.
- 383 backlog items: 367 `archived`, 299 of those with `pr_number > 0`; 1 `pr_pending`; 2 item PR URLs are in the `TylerStaplerAtFanatic` org (likely invisible to the personal token, see K5).
- `session_artifacts` blobs total 1.1 MB (max 32 KB). `~/.claude/projects` holds 8,302 JSONL files / 9.2 GB, of which 3,545 `agent-*` subagent transcripts / 4.7 GB are skipped today and become in scope under Story 7.
- `session/ent_repository.go:203` `SetMaxOpenConns(1)` with a 5000 ms busy timeout (`:190`); `scripts/install-service.sh:334-335` `StartLimitIntervalSec=600`, `StartLimitBurst=10`.
