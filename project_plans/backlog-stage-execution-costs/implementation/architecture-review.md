## Concerns

- [ ] **New (found this pass) — `CostSink` signature-change call-site inventory is incomplete by two sites.** Story 2.5.1's AC enumerates "14 existing `CallBlocking` call sites" as the full update surface, but `session/cost_sink.go:18` (`CostSinkForSessionUUID`'s returned closure, itself `CostSink`-typed) and `server/services/pr_creation_service.go:195` (a direct invocation of that closure, `session.CostSinkForSessionUUID(...)(draftCostUSD)`) are two more real sites that must change once `CostSink` gains a `priced bool` parameter. Neither is functionally on the GeminiCaller/triage/review path (both stay Claude-only), so there's no correctness risk — but the plan's task list (Task 2.5.1c: "the 14 files listed") should name these two files explicitly so the implementer isn't surprised by a `go build` failure Task 2.5.1d's own verification step would otherwise silently "explain" as something else. **Recommendation**: add `session/cost_sink.go` and `server/services/pr_creation_service.go` to Task 2.5.1c's file list, with the one-line fix (`func(usd float64, _ bool) {...}` and `(draftCostUSD, true)` respectively) spelled out.

- [ ] **Carried forward, not addressed by this repair pass — Epic 4.1 (Story 4.1.3/4.1.4)'s growth of `GetInsightsSummary` is now larger than originally flagged, but the Tech Debt Disposition entry's mitigation (a per-iteration helper) doesn't yet cover Story 4.1.4's second loop.** The existing Tech Debt Disposition row for `insights_service.go` (plan.md, Tech Debt Disposition table) proposes `accumulateRoleCost(roleMap, meta, costUSD, unpriced)` to bound the *first* loop's growth, which is a sound fix for Story 4.1.3.
