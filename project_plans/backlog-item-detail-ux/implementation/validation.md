# Validation Plan: backlog-item-detail-ux

**Date**: 2026-07-21

## Happy Path Scenario

Given a backlog item in `status: "review"` with a linked `headless-triage-*` session (a
**Headless Diagnostic Session**) and no active `useStuckBacklogItems()` match, when the user opens
the item's detail panel and then clicks the synthetic session row, then the **Lifecycle Summary**
(Stage Tracker showing "Review" active, no BlockerChip, Liveness Line populated) is visible
immediately with zero clicks, and the clicked row expands inline via `SessionDiagnosticPanel` to
show `TriageReviewPanel readOnly`'s summary/suggestions/tasks — with no navigation away from the
panel and no dead link.

## Test Stack

- **Unit**: Jest + React Testing Library (`@testing-library/react`), matching this codebase's
  existing convention in `web-app/src/components/backlog/BacklogItemDetail.test.tsx` (test names
  `ComponentOrFunction_should_ExpectedBehavior_When_Condition`, `describe` blocks scoped per
  epic/story where useful). Pure TS helpers (`sessionKind.ts`, `currentWorkSession.ts`,
  `useShowMore.ts`) use plain Jest (`describe`/`it`) without RTL. Go-side security review test
  (`session/backlog_review_test.go`) uses the standard Go `testing` package.
- **Integration**: Jest + RTL with mocked `useBacklogService`/`useStuckBacklogItems` hooks
  (`jest.mock`), fake timers (`jest.useFakeTimers()`) for poll-interval assertions — no live
  ConnectRPC backend in unit/integration tests, per existing codebase convention (see
  `LifecycleSummary.test.tsx`'s `useStuckBacklogItems` mock in Task 2.1.2c).
- **E2E / UX**: Playwright against `http://localhost:8544` (test server), per
  `.claude/rules/e2e-test-conventions.md`: `// @feature backlog:item-detail` header,
  `data-testid`/ARIA-role locators only, `expect(locator).toHaveAttribute(...)`/`toBeVisible()`
  instead of `waitForTimeout`, new page helper in `tests/e2e/pages/BacklogItemDetailPage.ts`.
  Accessibility contrast/forced-colors/icon-pairing checks lean on this repo's existing
  project-wide Axe Core CI gate plus a small number of manual checklist items for genuinely
  visual judgment calls (criteria 18, 19).
