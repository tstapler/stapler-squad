## P1 Items (address before implementation)
None. All five failure modes are P2 (likely-but-recoverable, bounded to incorrect button visibility — not data loss) or P3 (unlikely and/or already mitigated by non-goals/verification) — consistent with this being a complexity-1, low-impact, self-healing UX fix. The two P2 items (fail-open default unpinned, guard test inert in CI) are both cheap to close before merge: one additional test + one caveat sentence each.
