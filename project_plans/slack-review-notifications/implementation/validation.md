# Validation Plan: slack-review-notifications

**Date**: 2026-08-06

## Happy Path Scenario
Given a `SlackConfig` with a valid encrypted webhook URL and `NotifyOnQueueItem` enabled, when a new `session.ReviewItem` is added to the review queue via `ReactiveQueueManager.OnItemAdded`, then `SlackNotifier.NotifyReviewQueueItem` fires exactly one non-blocking Slack Block Kit POST containing the session name, reason, and a working dashboard deep link, without ever logging the webhook URL.
