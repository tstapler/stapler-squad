# Validation Plan: backlog-item-unarchive

**Date**: 2026-08-29

## Happy Path Scenario

Given a `BacklogItem` with `Status: "archived"` and a non-nil `ArchivedAt`, when the
user opens its detail view, confirms the archive-reversal implication is not shown
again (they're unarchiving, not archiving), and clicks the "Unarchive" button, then
`TransitionBacklogItemStatus` moves the item to `Status: "idea"`, clears `ArchivedAt`,
records a `BacklogStatusEvent{FromStatus: "archived", ToStatus: "idea"}`, and the item
reappears in default (non-archived) list views with the Unarchive button no longer
shown.

## Test Stack

- **Unit**: Go `testing` + `testify` (`require`/`assert`) for backend repository logic (`session/*_test.go`, in-package, no network); Jest + React Testing Library for frontend components (`web-app/src/**/*.test.tsx`), no real network — `useBacklogService`, `useSessionService`, and related hooks are `jest.mock`ed per the scaffold in `BacklogItemDetail.shipPR.test.tsx`.
- **Integration**: Go tests that exercise `EntRepository` against a real (test-scoped) ent/SQL client via `createTestEntRepository` — this is the codebase's standard integration layer for repository behavior (CAS preconditions, audit-event persistence), since ent has no mockable interface seam.
- **E2E / UX**: Playwright (`tests/e2e/`) against the isolated test-mode server spawned by `tests/e2e/global-setup.ts` (dynamically assigned port, isolated `--test-dir`, never the live `:8543` instance). Seeding uses existing debug-mutation helpers `createBacklogItemDirect`/`archiveBacklogItemDirect` from `tests/e2e/pages/BacklogMutations.ts`. Locators must be `data-testid` or ARIA roles only, no `waitForTimeout`, per `.claude/rules/e2e-test-conventions.md`.
