## Concerns
- [ ] **Task 1.1.6b goleak probe cannot see leaks from parallel tests** — `grep -rl 't.Parallel()' server/services` = 153 files, 1832 call sites. Go releases parallel top-level tests only after all serial top-level tests finish, so a `zz_leak_probe_test.go` serial test runs before any parallel test body has executed. `goleak.Find()` would also report the ~hundreds of paused parallel test goroutines as noise. The experiment answers the "Open" question only for serial-test leaks. Run it in `TestMain` after `m.Run()` (a `TestMain` already exists at `backlog_service_test.go:56`; use a scratch overlay, not an edit), or add `goleak.IgnoreTopFunction("testing.(*T).Parallel")`/filter by stack.
- [ ] **The plan's own R1 undermines the stated goal; make it a headline, not a risk row** — Go serial top-level tests never overlap, and `t.Setenv` panics once a test is parallel, so no two `HOME`/`STAPLER_SQUAD_TEST_DIR` mutators in this package can run concurrently. `homeEnvMu`/`stateEnvMu` are therefore effectively no-ops at runtime; they cannot be the cause of the observed failure nor its fix. The problem statement (requirements.md) and the helper header comment (`home_env_test_helper_test.go:19-26`, "two serial tests ... mutating HOME concurrently") assert the opposite. The PR title `fix: serialize ...` and the C2 message overclaim. Recommend: C2 type `test:`/`refactor:` not implying a fix, PR body leading with "baseline did not reproduce; locks are defensive; real reader-side leak not located", and rewrite or delete the false header claim (plan R2 only says "flag", which leaves a known-false comment in the shipped diff).
- [ ] **AC6 as a pass signal is non-discriminating** — baseline `main` passed 10 full runs and 45/45 targeted runs, so a green `-race -count=5` on the branch cannot distinguish fixed from never-failing. The plan acknowledges this but still scores AC6 "met if green". Add to Story 1.1.6 an explicit verdict line, "AC6: not falsifiable on baseline", so the PR checklist does not claim the race is fixed.

Measured: `grep -rn 'withFakeHome\(AsFile\|Path\)\?(' server/services | grep -v 'func \|home_env' | wc -l` = 60 (70 including the helper file); `withIsolatedStateDir*(` call sites = 139 (148 with helper).
