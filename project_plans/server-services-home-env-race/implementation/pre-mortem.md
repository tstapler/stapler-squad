# Pre-mortem: server-services-home-env-race
**Date**: 2026-10-13

Inputs: `plan.md` (incl. "Review amendments"), `requirements.md`, `research/findings.md`. Evidence labels: VERIFIED = command run or file read in this session; INFERRED = reasoned, not measured.

Scenario: the PR merged, all 7 ACs are checked off, and a month later `TempDir RemoveAll cleanup: directory not empty` is back in CI (or something worse landed with it).

## Facts this pre-mortem leans on

| Fact | Evidence |
|---|---|
| The two mutexes can almost never contend. `t.Setenv` panics once a test or ancestor called `t.Parallel()`, and Go runs serial top-level tests one at a time, so at most one test mutates `HOME`/`STAPLER_SQUAD_TEST_DIR` at any moment. Only a goroutine leaked from test A reading env live during test B can cross tests, and no goroutine takes these locks. | INFERRED from `testing` semantics; `config/config.go:124,132` (VERIFIED: `GetConfigDirForDir` reads both vars on every call); `research/findings.md` "Design limit" |
| Baseline `main` never reproduced the failure (10/10 plain+race runs), so a green AC6 on the migrated tree is also what an unfixed tree produces. | `research/findings.md` Verified section |
| Merges here are squash (one commit per PR, `(#NNNN)` suffix), so the three planned commits collapse into one on `main`. | `git log --oneline -8` on this branch (VERIFIED) |
| Branch is 14 commits behind `origin/main`; 6 of those touch `server/services`; 14 test files under `server/services` differ between `HEAD` and `origin/main`, including `backlog_service_test.go`, which this diff also modifies and which holds `TestMain`. | `git rev-list --count HEAD..origin/main`, `git diff --name-only HEAD origin/main -- server/services` (VERIFIED) |
| `TestEnvLock_ReentrantWithinOneTestAndSubtests` calls `withIsolatedStateDir` before `withFakeHome` (state, then home). `session_service_create_settings_env_test.go:41-42` does the same. 6 files call both helpers. | `home_env_test_helper_test.go:208-210`, `session_service_create_settings_env_test.go:41-42`, `grep -l` intersection (VERIFIED) |
| `ToInstanceData` still has a bare `*i.claudeSession` read at `session/instance_serialization.go:212-213` next to the fixed `diffStats` read. | file read (VERIFIED) |
| `TestMain` already runs under `goleak.IgnoreCurrent()` baselines in individual tests and calls `restoreState()` after `m.Run()`. | `backlog_service_test.go:56-75` (VERIFIED) |
