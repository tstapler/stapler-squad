# Validation Plan: terminal-resize-fit-loop

**Date**: 2026-07-24

## Happy Path Scenario

Given 3 concurrently-mounted `XtermTerminal` instances at a steady-state applied size (e.g.
`{cols: 80, rows: 24}`), when the browser tab is backgrounded and resumed, or the OS window is
resized once, then `ResizeObserver` kicks off `startSamplerIfNeeded()`, `sampleTick()` runs
`shouldScheduleFit()` against `proposeDimensions()`, `fitAddon.fit()` is called at most a bounded
number of times per instance (settling to zero within the `MAX_SAMPLES=20` / ~1s budget), the
`TerminalResize` RPC is sent at most once per instance for an actual size change (via
`useTerminalFlowControl.resize()`'s value-dedup against `lastSentDimsRef`), and none of the 3
instances' settling re-triggers churn in its siblings — CPU stays unpegged and typed input in
each terminal remains responsive throughout.

## Test Stack

- **Unit**: Jest 30 + ts-jest + `@testing-library/react` (`renderHook`/`act`/fake timers), following the existing pattern in `web-app/src/lib/hooks/__tests__/useTerminalFlowControl.test.ts`. Pure functions (`shouldScheduleFit`, `isSustainedMismatch`, `isFiniteResizeDimensions`) are tested directly with numeric/object fixtures — no mounting, no `ResizeObserver`, no real xterm.js `Terminal`.
- **Integration**: Jest + RTL component mounting (`render`) for `XtermTerminal.test.tsx` / `TerminalOutput.test.tsx`, with a hand-rolled `ResizeObserver` mock added to `web-app/jest.setup.js` (Task 4.1.1 — new; none exists in this repo today) plus per-test-file capture of the constructor's callback argument to drive fabricated `ResizeObserverEntry`-shaped deliveries. `@xterm/xterm`, `@xterm/addon-fit`, `@xterm/addon-webgl`, `@xterm/addon-canvas`, `@xterm/addon-web-links`, and `@xterm/addon-search` are all mocked at the module boundary (WebGL is unusable in jsdom) — decision logic and guard conditions are tested in isolation, explicitly not real WebGL/Canvas rendering behavior (Task 4.1.2).
- **E2E / UX**: N/A — AC7's manual verification is a documented manual checklist (plan.md Task 5.2), not automated E2E.
