## Happy Path Scenario
Given the seeded isolated instance (20 sessions across 4 windows: w1 = 8 panes, w2-w4 = 4 panes each; 200 backlog items; CPU throttle per `OPEN-DECISION-throttle-gate`, both conditions recorded; flags at their shipped defaults, `window_keep_alive` ON) and the baseline of requirements.md (14 identical `GetFeatureFlags`, 161 of 234 requests stalled ~30 s, 0.6-1.8 s switches), when the operator loads `/`, presses Alt+W then `2`, then navigates `/` -> `/backlog` -> `/`, then the run shows zero unary requests with Resource Timing blocked > 1 s, zero status-0 stalls, at most 1 `GetFeatureFlags`, the median `ssq:window-switch` for a retained window <= 150 ms with no long task >= 50 ms, `getBoundingClientRect` self-time at <= 20% of `baseline.json`, the p75 input-to-next-paint of the switch and nav click <= 200 ms (SM6), and echo p95 within +10% of baseline (SM7). *(Anchor: `tests/e2e/perf/frontend-responsiveness.spec.ts`, scenario `happyPath_should_MeetAllSevenSuccessMetrics_When_SeededFixtureRuns`.)*
