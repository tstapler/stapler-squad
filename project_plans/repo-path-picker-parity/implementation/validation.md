# Validation Plan: repo-path-picker-parity

**Date**: 2026-08-01

## Happy Path Scenario

Given a user with at least one existing session at `~/code/foo`, when they open the Omnibar,
switch to "New Project" mode, and focus the empty "Parent Directory" field, then the
suggestion dropdown shows `~/code/foo` as a history entry (most-recently-updated session
first) and selecting it fills the field, updates the Resolved Path Preview, and closes the
dropdown — completing path selection in 2 actions (focus, click) without typing the full path
from memory, using the same `RepoPathInput`/`PathCompletionDropdown` mechanism already proven
at the app's other 4 path-picker call sites.

## Test Stack

- **Unit**: Jest + React Testing Library (`web-app`), run via `cd web-app && npx jest --no-coverage --testPathPatterns="<pattern>"`. Covers `useSessionRepoPaths` (pure selector/hook logic against a minimal Redux `Provider` + test store) and `RepoPathInput`'s Escape-key handling (component-level, mocked `usePathCompletions`/`useSessionRepoPaths`).
- **Integration**: Component-level tests in `OmnibarCreationPanel.test.tsx` that wire the real `RepoPathInput` + `PathCompletionDropdown` components together with mocked `useSessionRepoPaths`/`usePathCompletions` hook boundaries (the "external call" being the `SessionService.listPathCompletions` RPC these hooks wrap) — verifies the composed swap behaves correctly without a live server. Playwright specs additionally serve as full-stack integration coverage against the isolated e2e test server (real Redux store, real (test-mode) RPC responses).
- **E2E / UX**: Playwright (`tests/e2e/`), run via `cd tests/e2e && npx playwright test session-create-new-project.spec.ts session-create-existing-worktree.spec.ts` against the isolated test server (`tests/e2e/global-setup.ts`). Covers suggestion visibility/ordering, manual entry, Escape containment, ARIA structure, and the 390×844 mobile viewport. Conventions per `.claude/rules/e2e-test-conventions.md`: `// @feature` header, no `waitForTimeout`, `data-testid`/ARIA-role locators only, new page-helper logic (if any) under `tests/e2e/pages/`.
