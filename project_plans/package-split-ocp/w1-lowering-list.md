## Headline findings

1. **The real lowering list is 414 declarations, about 4,300 LOC**, not the plan's 2,427 (a lower bound). 2. **`InstanceSnapshot` cannot go to `domain` (or a light `sessiondata`) yet.** It imports `github.CheckItem`/`ReviewItem`, `artifacts.SessionArtifactsBlob`, `tokens.ContextHealthVerdict` and `config` (`SessionType`); `artifacts` and `tokens` import `session/scanstate`, which pulls the `session/ent` tree. Measured with `go list -deps`: a `sessiondata` importing {github, artifacts, tokens, detection, log, config, hostclaim, git} has 86 module packages / 56 `session/ent` packages; without artifacts and tokens, 24 / 0; log and detection only, 11 / 0. **Fix: PR 1.0** lowers the small leaf types into `domain`, after which `sessiondata` is unnecessary (this also satisfies the owner decision to put the InstanceSnapshot struct in `domain`).
3. **`Session` (session.go), `InstanceToSession`, `SessionToInstance` and four `EntRepository`/`Storage` `*Session` methods are dead**: `Instance.ToSession` has 0 callers; `SessionToInstance` has 4 refs, all in tests; the four `EntRepository` methods are stubs returning "not yet implemented" (`session/ent_repository.go:1709-1730`; `Storage` twins at `storage.go:1079-1092`). **Delete, don't lower 246 LOC.**
4. **The raw-field audit's "missing from snapshot" list is mostly wrong**: `LastViewed`, `LastAcknowledged`, `LastTerminalUpdate`, `LastMeaningfulOutput`, `LastOutputSignature`, `LastAddedToQueue` (plus `LastUserResponse`, `ProcessingGraceUntil`) are promoted from the embedded `ReviewState`, which the snapshot embeds. Truly missing: the Retry fields (embedded `RetryState`), `RetryPolicyOverride`, `GitManager`, `ExistingWorktree`.
5. **Alias removal is the real bulk codemod**: `session/backlog.go` has 42 re-export aliases (580 external non-test refs, 2,428 test refs, 1,569 in-session), `review_queue.go` has 21 aliases of `session/queue` (115 / 209 / 527). `scoping` has no alias-removal tool (gopls rename or `go fix //go:fix inline` are candidates, UNVERIFIED for aliases).
