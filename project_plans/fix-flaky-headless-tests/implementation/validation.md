**Date**: 2026-08-06

## Happy Path Scenario

Given a `ProcessRunner` constructed via `NewShellWrappedProcessRunnerForTesting(scriptPath)` (interpreter `"sh"`, claudeBin the freshly-written fake-claude fixture script), when `Pool.CallBlocking` invokes it, then `executor.StartProcess` execs the pre-existing, already-trusted `sh` binary with the fixture script path prepended to argv — never asking the OS to approve direct execution of a freshly-written temp file — so clusters 1 and 2's tests pass reliably regardless of platform-level exec restrictions (Gatekeeper/TCC/EDR), while every production `ProcessRunner` (interpreter left at its zero value `""`) execs `claudeBin` exactly as before, with zero behavior change.
