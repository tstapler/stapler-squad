## Happy Path Scenario
Given the baseline in requirements.md (a hidden `review:*` session finishes and today pushes "Session Completed" with an unopenable "View Session", while ten simultaneous toasts cover the phone terminal), when the operator has both flags on and a hidden review session completes routinely and then a second hidden session fails, then the routine completion produces zero push, toast and history row on every channel, the failure produces exactly one toast, push and history row whose "View output" opens the session read-only in one tap, the ten-toast burst shows exactly 3 cards (1 on a 390x844 phone) with a "+N more" chip and a "Move all to tray" that empties the deck while every history row (including pinned decisions) stays unread in the tray, and opening and closing the tray leaves the xterm `cols x rows`, root DOM node and scrollback untouched and returns focus to xterm.

Anchor tests: `T-MX-01` (backend, every channel), `T-E2-14` plus `T-E2-15` (hidden quiet then failure, e2e), `T-E2-02` and `T-E2-03` (stack cap), `T-E2-06` (tray invariants).

## How to read this document
- **Requirement IDs** (inventory below) are the requirements.md items, one ID each: `SM` success metrics, `SC` in-scope items, `C` constraints, `NFR`, `OBS`, `RC` risk control, `FR` feasibility risks, `RH` rabbit holes, `OQ` open questions, `OS` out-of-scope guards.
- **Test IDs**: `T-<area>-NN` for the Requirement to Test Mapping; UX criterion IDs (`TD-1`...) are the `design/ux.md` ids and appear in the UX table. Counts are by script.
- **Type** column: `Unit`, `Integration` (real collaborators or real bus/subscribers/store; includes type-based `Guard` scans, marked in Scenario), `E2E` (Playwright), `Migration`. **Scenario** column: `Happy path`, `Error path`, `Edge`, `Characterization`, `Concurrency`, `Guard`.
- Path abbreviations: `DG/` = `server/deliverygate/`, `SV/` = `server/services/`, `NT/` = `server/notifications/`, `PS/` = `server/push/`, `EV/` = `pkg/events/`, `ST/` = `session/streamhub/`, `WUI/` = `web-app/src/components/ui/`, `WLIB/` = `web-app/src/lib/`, `WS/` = `web-app/src/components/sessions/`, `E2E/` = `tests/e2e/`. A `__tests__/` folder is implied for jest files.
- Naming: Go `TestUnit_ShouldExpected_WhenCondition`; jest/Playwright `unit_should_expected_when_condition` (the `methodName_should_ExpectedBehavior_When_Condition` pattern).
- Former Stretch rows (Quiet mode, hotkey, `top-sheet`/`landscape-panel`, push SW handoff) are ordinary rows since operator decision O8; they are authored with their story, which is sequenced last in its epic (the hotkey row records "no safe chord" if the Task 4.2f spike finds none).
