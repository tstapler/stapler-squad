## P1 Items (address before implementation)

- [ ] **#1 (steer regression)** Plan does NOT contain the prevention. grep of `plan.md` and the ADRs for `SessionsSection`, `isSteerable`, `backlog:session-steer` returns nothing.

  Evidence (VERIFIED):
  - `web-app/src/components/backlog/BacklogItemDetail.tsx:628` calls `updateSession(s.sessionId, { steerMessage: message })`.
  - `web-app/src/lib/backlog/sessionKind.ts` `isSteerable` returns true for `review` role sessions that have not ended.
  - `server/services/session_service_diagnose.go:54-60` `SpawnReviewSession` creates the session with `Hidden: true`.
  - `server/services/session_service_update.go` steer branch (around line 313) is the branch Story 5.2 and Task 5.2b guard.

  Plan patch text:

  1. In "Operator decisions", add row: `| O7 | Backlog "Steer" composer on hidden review sessions | OPEN, must be DECIDED before Story 5.2. Recommended: keep it working. The terminal-view read-only guarantee covers stream Input/Resize and TerminalService.WriteToSession; the UpdateSession steer branch stays allowed for sessions whose HiddenKind is review AND that are linked to a live backlog item, with an audit line (same sink as Story 5.6) and an explicit entry in the Story 5.1d scan allowlist.   2. Story 5.2, replace the bullet "Steer branch of `UpdateSession` rejects for hidden" with: "Steer branch of `UpdateSession` rejects hidden targets **except** the O7 exemption. *Given* hidden review session `r1` linked to a live backlog item, *When* the backlog composer sends `steerMessage`, *Then* it succeeds and one audit line is written (characterization test written FIRST and green before the guard lands). *Given* hidden triage/diagnose/other or an unlinked review session, *Then* `FailedPrecondition`."
  3. Add Task 5.2d: "Characterization test of `BacklogItemDetail` steer to a hidden review session (client mock plus server `UpdateSession` test), run on `main` before Task 5.2b."
  4. Story 5.1d scan: allowlist is "exactly two entries" (Reply and the O7 steer), each requiring its narrow capability parameter.
