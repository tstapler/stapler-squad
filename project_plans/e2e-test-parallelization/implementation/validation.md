**Date**: 2026-10-25

## Happy Path Scenario

Given the post-#1166 10-way sharded `e2e-next`/`e2e-bun` CI jobs each taking ~25-40 min, when this plan's Phase 3 changes (`fullyParallel: true` shard rebalancing, Chromium-only install isolation) ship as two independently-revertable PRs, then the slowest-shard-to-`web-build-gate`-verdict wall-clock measurably drops (or at minimum does not regress) with zero new `e2e-baseline-compare.ts` `fail`-severity findings and zero newly-uncovered routes in `route-coverage-manifest.ts`'s before/after diff.

## Test Stack

- **CI-config correctness**: `actionlint .github/workflows/build.yml` (required before any workflow-file push, per requirements.md's own constraint).
- **Gate-membership regression**: `node --test web-app/scripts/__tests__/web-build-gate.test.mjs` (`node:test`, no separate test runner needed for this file) — existing suite plus the new Task 3.2.1d case.
- **Baseline-classification regression**: `scripts/e2e-baseline-compare.ts`, invoked as the `e2e-bun` job's "Run the baseline comparator" step (`build.yml:644-655`); read via `gh run view <run-id> --log` or the job's `$GITHUB_STEP_SUMMARY`.
- **Route-coverage regression**: `scripts/route-coverage-manifest.ts`, run locally before/after via `ts-node scripts/route-coverage-manifest.ts --baseline tests/e2e/baseline/next-e2e-baseline.json --expected-diff tests/e2e/baseline/bun-expected-diff.json --route-meta web-app/src/app/route-meta.ts --out <file>`, diffed with `jq`.
- **Real CI timing evidence**: `gh api repos/tstapler/stapler-squad/actions/runs/<id>/jobs` for per-shard/per-step start/complete timestamps — the only "performance test" this project has, and it requires a real pushed CI run (wall-clock blocker, not an agent-token cost).
- **Config/doc static checks**: `grep`/`git diff --stat`/`git log` one-liners, used throughout as the "did the edit touch only what it claims to touch" check — standing in for a linter where no dedicated tool exists for Markdown finding-note or Playwright-config-field scope.
- No Jest/Go test frameworks apply: this project adds no application code, so there is no new `*_test.go` or `*.test.tsx` surface beyond the one `web-build-gate.test.mjs` case.

## Coverage Targets and How to Measure

This project has no statement/branch coverage target — there is no new application code to instrument. Coverage here means **requirement-to-check traceability** and **CI-outcome correctness**, measured as:

- **Requirement coverage**: 5/5 of requirements.md's Scope → In Scope bullets have ≥1 corresponding test/check in the mapping table above (100%).
- **Gate-test pass rate**: `node --test web-app/scripts/__tests__/web-build-gate.test.mjs` must exit 0, including the new Task 3.2.1d case, before any Phase 3 PR is opened (Task 3.1.1b, Task 3.2.1c) and again after real CI runs (Task 3.1.2a, Task 3.2.2a implicitly, since a red gate test would itself be a CI failure).
- **Comparator cleanliness**: zero new `severity: "fail"` findings from `scripts/e2e-baseline-compare.ts` on every Phase 3 PR's real CI run — this is the project's actual regression-coverage proxy, standing in for "did we break any of the 193 specs' pass/flaky/fail classification."
- **Route-coverage non-regression**: zero newly-`covered: false` routes from `scripts/route-coverage-manifest.ts`'s before/after diff, specifically load-bearing for Story 3.2.1/3.2.2 (the browser-install isolation change is the one story that could plausibly drop real coverage).
- **Timing evidence, not a threshold**: no fixed percentage target is set (requirements.md explicitly leaves the SLO as "directionally faster, to be quantified by research"); each of Story 3.1.2/3.2.2 instead records an absolute before/after number via `gh api` and treats "no regression" as the hard floor and "measurable improvement" as the goal.
- **Scope-containment checks**: `git diff --stat` / `git log` checks (Stories 1.1.1, 2.1.1, 2.2.1, 4.1.1) substitute for coverage tooling on stories whose correctness criterion is "touched nothing outside its stated scope," not "percentage of lines exercised."
