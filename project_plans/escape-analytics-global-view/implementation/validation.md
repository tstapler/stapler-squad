# Validation Plan: escape-analytics-global-view

**Date**: 2026-08-11

## Happy Path Scenario
Given the Baseline state (multiple sessions have recorded `EscapeEvent`s and no cross-session comparison exists in the UI), when the user clicks the "All Sessions" tab on `EscapeAnalyticsPage`, then the page renders the fleet-wide sequence histogram, total/mangled counts, mangle rate, and a per-session breakdown table (default-sorted by mangle rate descending) sourced from a single `GetEscapeAnalyticsGlobalSummary` RPC call — proving a systemic vs. isolated mangle-rate spike is now visible without clicking through sessions one by one.

## Test Stack
- **Unit (Go)**: `go test` + standard library `testing`, table-driven where applicable — pure-function tests (`escapeMangleRate`) that touch no DB, plus the nil-`analyticsClient` guard test (early return, no DB call).
- **Integration (Go)**: `go test` against the real ent-generated client over a temp/in-memory SQLite analytics DB (same fixture-seeding convention as the existing `GetEscapeAnalyticsSummary` tests in `analytics_escape_service_test.go`) — anything that issues a real `GROUP BY` query.
- **Unit (TypeScript)**: Jest + React Testing Library, mocked `@connectrpc/connect-web` client — hook-level tests with no real network/store.
- **Integration (TypeScript)**: Jest + RTL component tests (`EscapeAnalyticsPage.test.tsx`) that compose the page, both hooks, and a mocked RPC client to verify cross-component wiring (hook suspension, re-fetch on filter change).
- **E2E / UX**: Playwright + Allure, per `.claude/rules/e2e-test-conventions.md` (feature annotation header, no `waitForTimeout`, `data-testid`/ARIA-role locators only, page helpers under `tests/e2e/pages/`), against the isolated auto-managed test server. Manual checklist for the handful of criteria automation can't cheaply cover (disabling CSS to verify non-color cues, full keyboard-only accessible-name sweep) — the automated Axe Core / Lighthouse CI gates already run on PRs touching `web-app/src/` and cover the contrast/ARIA-name checks structurally.
