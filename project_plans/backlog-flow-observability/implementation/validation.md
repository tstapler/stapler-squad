# Validation Plan: backlog-flow-observability

**Date**: 2026-11-05 (patched in Phase 4 against `consistency-review.md`, `pre-mortem.md` and the architecture re-review)

## Happy Path Scenario
Given the live-shaped workspace DB (about 258k status events, 35 thrash items, 528 verdicts, per requirements Baseline) and an injected clock, when Tyler opens `/backlog/flow?window=30` (or Claude calls `get_flow_summary window_days=30`), then one sectioned response renders tiles, funnel, rework causes, review gate, stuck reasons and a "N items thrashing" banner in under 1s, thrash items appear under anomalies and not in dwell totals, and every displayed number opens the items behind it. *(Anchor for all tests below: `TestAggregator_should_ReturnSectionedSummary_When_ThrashFixtureAndFixedClock` and `flow-page happy path` e2e.)*

## Conventions applied to every test
- Go naming follows the repo (`TestSubject_should_Behavior_When_Condition`, see `server/mcp/tools_backlog_test.go`). Type names use the plan.md Domain Glossary (`FlowWindow`, `Span`, `ThrashSpan`, `FlowSummary`, `SectionStatus`, `DrillKey`, `Sources`).
- Deterministic and fast (`deterministic-fast-tests` skill): a fixed `Clock` is injected everywhere (no `time.Now()`); TTL and staleness tests advance the fake clock, never sleep; concurrency tests use a `sync.WaitGroup` plus a start barrier channel, not sleeps; the 258k-row perf test is skipped unless `SSQ_FLOW_PERF_DB` is set; ent tests use the in-memory SQLite helper (`docs/explanation/test-io-storage-isolation.md`); Jest uses fake timers and an injected `now`.
- E2E (`e2e-test-conventions` skill): `// @feature backlog:flow, ...` header, no `waitForTimeout` (Playwright `page.clock` for time, `expect(...)` auto-wait), `data-testid` or ARIA locators only, helper `tests/e2e/pages/BacklogFlowPage.ts`, isolated server from `global-setup.ts`, error and stale states via `page.route` interception of the ConnectRPC calls.
- Registry (CI gate): each new RPC JSON under `docs/registry/features/backend/` and the `backlog:flow` frontend entry are `tested:true` with `testIds` naming the tests marked (REG) below.
- Golden fixtures (Story 0.1.3): `session/flow/testdata/{events_thrash,verdicts,stuck}.json`; fixtures assert shapes, not live totals.
