## Other risks considered (not top 5)

- **P3, catastrophic if wrong**: the MCP response carries free-text item titles and request-review notes from other agents into Claude's context. Story 3.2.1 sanitizes once at the adapter; a missed field (for example a `verdict.summary` or `per_criterion` text added later to the proto) is an injection path into the tuning loop. Prevention: a test that walks the proto descriptor and fails on any string field in the MCP-marshalled response that is not on an explicit allow-list or sanitized-fields list.
- **P3**: `Cause` classification by note prefix and `VerdictClass` by summary text drift when the pipeline's wording changes (the notes are free-form constants in a 4018-line file this plan promises not to edit). `unclassified` is reported, so the failure is visible, but the headline "judgment-only" rates silently degrade. Prevention: a Data notes threshold (for example `unclassified > 10%` shows an amber warning).
- **P3**: Thrash thresholds (`G=15m`, `N=6`, `M=1h`) are tuned against one month of two loop families. A new loop with a slower cadence (30m) is invisible and counted as real rework. Prevention: the per-item transition-rate outlier list in ADR-002 is the backstop; add an AC that it fires on a fixture with a 30-minute-cadence loop.
