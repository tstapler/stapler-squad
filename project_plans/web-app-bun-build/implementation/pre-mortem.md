# Pre-mortem: web-app-bun-build
**Date**: 2026-10-19

Scenario: three months after cutover (PR 8), the migration failed or caused an outage. Inputs read: `implementation/plan.md` (Plan-level decisions, Migration Plan, Spike Gates, Stories 2.7, 3.0-3.4, 5.1-5.11, 7.9-7.13, Phases 8-9, Repair log), `requirements.md`, `adversarial-review.md` (open items), `server/middleware/static.go` (index.html is `no-cache`; `/_next/` is `immutable`, so deploy skew is limited to stale open tabs). Evidence labels: VERIFIED = opened in this run; INFERRED = reasoning from the plan text.

The plan already closes most of what the brief lists (lockout walk + `verify-output`, patch canary, `--tmux-keep-server` precondition, ModeStamp, baseline comparator). The failure modes below are the residual holes that survive those controls.
