# Pre-mortem: session-card-subtitle-dedup
**Date**: 2026-08-06

## Failure Modes

| # | Failure | First Symptom | Prevention | Severity |

| 1 | For the default "New branch (isolated)" creation mode, real worktree paths get a random hex timestamp suffix appended (`session/git/worktree.go:199-202`: `worktreePath = worktreePath + "_" + fmt.Sprintf("%x", time.Now().UnixNano())`), so `basenameOf(session.path)` is `fix-auth_18f2a9c1b4e0`, never exactly `session.title` — AC2's Path/Working Dir dedup silently never fires for the majority of real sessions, even though the plan's own example paths (no suffix) and Story 1.2.2's rationale ("a worktree directory named after the session") imply it will. | Branch row correctly disappears (branch names have no timestamp suffix) but Path/Working Dir rows for the exact same, exact-duplicate-titled sessions never do — looks inconsistent/half-fixed rather than broken outright. | Before implementing Epic 1.2, pull or construct a real `session.path` sample from a new-worktree-mode session (or re-read `session/git/worktree.go`'s path-construction code, not just `SessionsTable.tsx`/`page.tsx`'s basename idiom) to confirm whether the suffix is present for the sessions this feature targets. ## P1 Items (address before implementation)
None. No failure mode here is both likely and outright catastrophic (crash, data loss, or irreversible corruption) — the worst outcomes are silent no-ops (dedup doesn't fire where expected) or bounded information loss (task-progress subtext), both recoverable via a follow-up display fix with no data at risk. Item #1 (worktree-path timestamp suffix) is the one to fix first regardless of severity label, since it undermines the feature's core value proposition for its primary target case (new-worktree-mode sessions) — treat it as the top of the P2 queue.

## Summary
5 failure modes: 0 P1, 4 P2, 1 P3.

Top failure mode: the plan's Path/Working Dir dedup (AC2) is built and tested against example paths that don't reflect how `session/git/worktree.go` actually constructs new-worktree session paths — real paths carry a random hex timestamp suffix (`fix-auth_18f2a9c1b4e0`), so `basenameOf(session.path) === session.title` will rarely-to-never be true for the dominant "New branch (isolated)" creation mode, meaning the feature could ship, pass all its tests, and still not visibly reduce Path-row redundancy for most real sessions.
