# Workflows

A workflow is a reusable preset for starting a session with a fixed command, directory and model, for example a "design doc session". Instead of re-entering the same options, you run the workflow and supply only the varying input.

Open [Workflows](/workflows) to create, edit and run them. A workflow can include a prompt template with an `{{input}}` placeholder that is filled in from the argument you give when running it.

Workflows can also be created and run by agents through the `create_workflow` and `run_workflow` MCP tools.
